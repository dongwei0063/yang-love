## 👤 第一次使用

### 第一步：注册账号

1. 打开网址，进入登录页面
2. 点击「**注册**」标签
3. 填写：
   - **用户名**（给自己取个昵称）
   - **密码**（至少4位）
   - **TA的名字**（可选，之后可改）
4. 点击「**注册 · 开始甜蜜之旅**」
5. 注册成功后自动进入首页，会看到你的 **情侣房间码**（6位字母，如 `ABC123`）

### 第二步：绑定情侣

**你（发起方）：**
注册后自动生成情侣码，页面会显示「**情侣房间码**」

**TA（接收方）：**
1. 打开同一网址
2. 注册账号（填用户名 + 密码）
3. 注册时或注册后在登录表单的「情侣房间码」栏填入你分享的码
4. 点击登录 → 自动绑定成功

> 💡 绑定后两人的所有数据（日记、纪念日、愿望等）实时双向同步

## 📝 恋爱日记

**写日记：**
1. 点击「恋爱日记」
2. 点击右上角 ✏️
3. 选择今日心情（😊🥰😢😤🤗😴）
4. 输入日记内容
5. 点击「保存」

**查看历史：**
- 点击日历上的日期可查看/编辑当天日记
- 左右箭头切换月份

---

## 🎯 纪念日

**添加纪念日：**
1. 点击「纪念日」
2. 点击右上角 ➕
3. 填写名称（如：交往纪念日、生日）
4. 选择日期
5. 选择图标 💕🎂💍✈️🏠🌍
6. 点击「保存」

**倒计时规则：**
- 未到的纪念日：显示「还有 X 天」
- 已过的纪念日：显示「已一起 X 天」

**删除：** 长按/点击纪念日卡片确认删除

---

## 🌸 经期追踪

**记录经期：**
1. 点击「经期追踪」
2. 点击右上角 ➕
3. 选择「经期第一天」的日期
4. 可选：填结束日期、心情、备注
5. 点击「保存」

**智能计算：**
- 自动按 28 天周期计算下次到来时间
- 首页卡片实时显示当前状态

## ❓ 常见问题

**Q: 情侣码忘记了怎么办？**
A: 在设置页可以看到自己的情侣码

**Q: 对方看不到我的数据？**
A: 确认两人使用了同一个情侣码，且都成功登录

**Q: 云同步不生效？**
A: 检查网络连接，或在设置页点击「同步数据」手动触发

**Q: 想换情侣绑定？**
A: 在设置页点击「绑定新的情侣码」，输入新码即可
